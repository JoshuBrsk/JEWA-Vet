# Base de Datos

## Nombre del proyecto

Sistema de Gestión Veterinaria JEWA-Vet.

## Motor de base de datos

SQL Server.

## Objetivo

Almacenar y organizar la información del sistema veterinario para facilitar su consulta y administración.

## Tablas propuestas

* **Clientes:** información de los propietarios de las mascotas.
* **Mascotas:** datos de los animales registrados.
* **Veterinarios:** información del personal veterinario.
* **Citas:** programación de consultas veterinarias.
* **Tratamientos:** información de los tratamientos aplicados.

## Consideraciones

La base de datos deberá mantener la integridad de la información y establecer relaciones entre las tablas según los requisitos del sistema.
